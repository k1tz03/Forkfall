## 0. Comment lire ce chapitre

### 0.1 Ce qu'un entraîneur a que les autres n'ont pas

L'entraîneur est le fusible : il est le seul rôle qui ne décide de rien et qui paie tout. Le joueur a un corps, le président a un chéquier, le sélectionneur a un pays ; l'entraîneur a un banc, un adjoint qui dîne, un capitaine qui a lu la compo dans le journal, un kop qui la vote, un président qui a deux discours prêts, et un journaliste qui note le silence. Sa jauge fragile est DIRECTION : le président s'ennuie de lui à raison d'un point toutes les deux cartes. Tout ce qu'il peut faire, c'est composer, promettre, ou se taire. Tous les dilemmes tiennent là-dedans : à qui est ce club, et combien de temps avant qu'on le lui dise.

Le ton du banc : tendre avec le vestiaire (le vieux gardien, le petit, le capitaine qui a mal au genou), féroce avec le bureau (le chèque non daté, le fax de trois lignes, la plaque « ambassadeur »), sec avec la presse, jamais méprisant avec la tribune. Le drame est rare (Clow à l'hôpital, la tribune, le flacon B) et jamais en première saison.

### 0.4 Conventions propres au chapitre

- `{club}`, `{ville}`, `{rival}` sont tirés par le moteur ; `{coach}` est l'entraîneur viré de l'intérimaire (entité existante). On ne nomme un club de la table de la charte que pour parler d'un autre club (Valentienne pour Malbec, Néville pour le premier banc de Vukić, le Real Montoya, Al-Dorado FC, Corbelin).
- `{monnaie}` rend francs avant 2002 et écus ensuite ; « cent francs » reste écrit en dur dans les cartes existantes de 1990.
- Les scènes qui reprennent une carte existante la citent par id avec la mention ∃ et ne la réécrivent pas ; ce qu'elles ajoutent (variante, réaction, trace, lecteur) est marqué **+**. Une carte ∃ dont le texte est cité l'est mot pour mot, pour que l'intégrateur puisse vérifier.
- Une intrigue rejouable porte sa variante « encore » sur `plays()` ; aucune de ses cartes n'est `once`. Les intrigues `co.*` sont partagées avec le joueur (chapitre 10) : ce chapitre écrit la version banc ; la variante joueur y est signalée, jamais écrite deux fois.
- Le drame (une intrigue sur dix) est marqué **[drame]** ; jamais en S0, jamais deux d'affilée dans un réservoir (les pools sont ordonnés pour ça).
- Les ancres de script sont nominatives une carte sur deux (A1, A4, A7, A8, A9, la rentrée), jamais A5, A6, la veille (spec § 1.8) ; les réactions qui suivent une carte nominative ne portent pas le nom.
